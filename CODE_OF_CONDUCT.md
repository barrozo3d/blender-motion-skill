# Code of Conduct

## Purpose

This project is a **knowledge-gathering and expert-consultation tool**, not a content-reproduction tool. It ingests publicly available Blender tutorials, documentation, and articles to build a searchable reference library, and uses that library to answer technical questions and write code — the same way a human artist studies tutorials to learn a craft, then answers questions from that learned understanding.

### What this project is for

- Learning and indexing **how techniques work** — steps, node/modifier/setting names, and workflow reasoning — from tutorials and documentation.
- Answering technical questions and writing Python/geometry-node code based on that learned understanding.
- Preserving and citing sources: every ingested entry keeps its original title, author, and URL, and every consultation answer cites which tutorial it drew from.

### What this project is explicitly NOT for

- Reproducing, redistributing, or republishing anyone's copyrighted tutorial video, article, or documentation text.
- Copying, cloning, or reproducing anyone's finished artwork, render, model, shader, or creative asset.
- Claiming authorship of a technique, workflow, or asset that originated with the tutorial creator being cited.
- Circumventing paywalls, terms of service, or licensing restrictions of any ingested source.

## Expected Behavior

Anyone contributing to or operating this skill should:

- Ingest only sources they have the right to access and learn from (public tutorials, official documentation, content they've purchased or licensed).
- Preserve source attribution (author, title, URL) in every ingested entry — never strip it.
- Use the knowledge base to **explain and teach**, not to regenerate someone else's copyrighted content verbatim.
- Treat "core technique" extraction (steps, settings, reasoning — captured in each tutorial's `Structured Notes` section) as the intended scope for personal learning and consultation. Wholesale transcript or frame reproduction beyond what's needed for that purpose is not this tool's purpose.
- When using Mode 2 (the live Blender connection via the BlenderMCP addon), only apply it to projects and assets the user has the rights to modify.

## Reporting Concerns

If you believe this project's knowledge base contains content ingested in a way that infringes on a creator's rights, or that the skill is being used to reproduce someone's work rather than to learn from and cite it, open an issue on this repository describing the concern.

## Scope

This is a single-maintainer tool, not a community project with contributors to moderate — this document exists to state the ethical boundary of what this project ingests and produces: **knowledge and consultation, never copying or reproducing someone else's work, render, or art.**
