## Structured Notes

### Core Technique
A quick survey of the built-in **Grease Pencil brush presets** in Blender's **2D Animation** workspace (Draw Pencil, Draw Noise, Draw Marker, Draw Ink, Draw Block) — showing how each preset's default stroke style (thin/uniform, wobbly/textured, thick/tapered marker, bold ink, solid painterly block) changes the character of a hand-drawn line without any manual settings adjustment.

### Key Steps
1. Open the **2D Animation** workspace and locate the brush-type dropdown in the top toolbar (defaults to "Draw Pencil").
2. Click the dropdown to switch between the built-in Grease Pencil brush presets: **Pencil** (thin, uniform sketch line), **Noise** (textured/grainy wobble), **Marker** (bold, smooth stroke), **Ink** (tapered, calligraphic-style stroke), **Block** (thick, solid painterly stroke).
3. Draw with each preset to compare stroke character — no manual radius/strength tuning is required to get distinctly different line qualities, since each preset ships with its own default settings.
4. Use these presets as starting points for different drawing styles (clean line art vs. rough sketch vs. bold poster-style linework) before customizing further if needed.

### Nodes / Settings
- **2D Animation workspace > Draw Mode > brush dropdown:** Pencil, Noise, Marker, Ink, Block (built-in Grease Pencil brush presets).
