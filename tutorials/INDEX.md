## How to Read This Index

Each entry format:
```
### [Tutorial Title]
- **Source:** YouTube / Article / Documentation
- **URL:** link
- **Author:** creator name
- **Blender Version:** version shown
- **Tags:** #technique #category #level
- **Summary:** 2-3 sentence description of what's taught
- **File:** tutorials/filename.md
```
