[0:00] A little while ago I was sending the new XP-Pen Artist Pro Gen2 drawing display, so that I could test it out and review it for you guys.
[0:08] I've always happily worked with a pretty ancient screenless pen tablet, and I'd never tried a drawing display before, so I was curious what that would be like.
[0:17] I tried it on both my MacBook and my PC.
[0:20] The method for connecting them is a little bit different on each.
[0:23] On the MacBook you can just plug it in with a USB-C cable, just make sure on the MacBook that you use the first USB-C port.
[0:31] Then it just works as a second screen.
[0:33] You'll also need to download the XP-Pen software from their website.
[0:37] On PC, if you don't have a USB-C input, like my PC, which only has USB-A input ports, you can use a special cable that has an HDMI plug for your graphics card, so you just connect it like you would a second monitor.
[0:50] Except this cable also has an additional USB-A connection that you need to plug into your PC and another USB-A connection for the power adapter.
[0:58] Luckily, all of these cables come in the box with the drawing display.
[1:02] Also in the box is the pen, of course.
[1:04] By the way, all these things feel very solid and heavy and are made of metal.
[1:08] The pen comes with various extra nibs, which is nice in case one wears out.
[1:13] There's also this little remote pad, which you can either hook up directly with a USB-C cable or with a Bluetooth dongle that it comes with.
[1:20] I think this remote has the potential to make working with the drawing display much more accessible, because it can replace the most used keyboard shortcuts.
[1:28] For example, you could use the ring button to change the brush radius in sculpt mode, or you could set the auto buttons for alt control shift, maybe also some mode changes like sculpt object edit mode, and of course set one for the quick favorites menu.
[1:42] You could get pretty far without having your keyboard in the way, which is one of the challenges when working with one of these drawing displays.
[1:49] Speaking of challenges, one of the downsides I found is that when you're using this tablet in a room with a ceiling window or built-in ceiling lights, the reflection on the screen can make it harder to see what you're doing.
[2:00] In that case, I recommend working somewhere else or just turning off those lights.
[2:04] Luckily, this is a pretty portable setup that you can use in combination with your laptop.
[2:09] And if I read it correctly from the manual, you could even plug this into your phone.
[2:13] Practically speaking, in the XP-Pen software, you can change what the buttons on the pen do.
[2:18] First, you need to add Blender in the app list, because the options are set per app.
[2:24] I like to have the nib set as left-click and then the lower button as middle mouse, so that I can hold it and navigate in the 3D viewport.
[2:31] And then the second button as right-click for context menus.
[2:35] At first, I thought that the nib can't act as left-click because there is no option there, but fortunately it's set as left-click by default.
[2:42] With the pen setup this way, you can press the lower button and hover to rotate the view, hold Ctrl to zoom and Shift to pan.
[2:50] And press the second button to right-click and touch the nib on the screen to click or select objects.
[2:56] In the Windows settings under the Monitor settings, you can choose to either extend the screens, which means that the tablet works as a second monitor,
[3:04] or to duplicate the screen, which means that your primary monitor and the drawing display will show the same thing.
